# Пастельня — сайт-каталог і магазин кондитера

Сучасний сайт для домашньої кондитерської: меню з фото, фільтри, кошик, замовлення в месенджер або на пошту, індивідуальні замовлення і зручна адмін-панель.

## Що вміє
- **Меню «меню в меню»:** категорії → підкатегорії з фото (Торти → Бенто, Весільні, Мусові…).
- **Фільтри:** ціна, розмір/вага, начинка, особливості (без глютену, без цукру, веган), без алергенів, привід; сортування.
- **Картка виробу:** розмір із ціною, начинка, напис на торті, кількість, склад, алергени, умови доставки.
- **Кошик і оформлення:** ім'я, телефон, зручний месенджер, дата/час, самовивіз або доставка.
- **Замовлення надходить кондитеру:** автоматично на пошту (Web3Forms) і/або кнопками «Надіслати в Viber / WhatsApp / Telegram» з уже готовим текстом.
- **«Написати кондитеру»:** форма індивідуального замовлення з фото-прикладом.
- **Адмін-панель** (`#/admin`): замовлення зі статусами й кнопками «Подзвонити/Viber/WhatsApp»; вироби з фото (автоматичне стискання), розмірами, начинками, складом, алергенами, позначками «Хіт»/«Новинка»; категорії й підкатегорії з фото; налаштування (назва, контакти, куди надсилати замовлення).
- Адаптивний дизайн для телефона, планшета й комп'ютера.

## Режими роботи
**Демо (за замовчуванням):** працює одразу. Вироби, категорії й замовлення зберігаються лише в браузері того, хто відкрив адмінку. Підходить для показу.

**Бойовий (Firebase, безкоштовний тариф):** вироби бачать усі відвідувачі, замовлення збираються в адмінці.
1. Створіть проєкт на https://console.firebase.google.com → додайте **Web app** → скопіюйте `firebaseConfig`.
2. **Authentication → Sign-in method → Email/Password** → увімкніть. У **Users** додайте користувача (пошта й пароль кондитера).
3. **Firestore Database → Create database** (production mode). На вкладці **Rules** вставте вміст `firestore.rules`, замінивши `owner@example.com` на пошту кондитера → **Publish**.
4. У `js/config.js` вставте `firebaseConfig` у `FIREBASE`, а пошту кондитера — в `ADMIN_EMAILS`.
5. Увійдіть на `#/admin` поштою й паролем і додайте свої вироби (демо-меню показується, доки в базі немає жодного виробу).

## Листи із замовленнями на пошту
Зареєструйтесь на https://web3forms.com (безкоштовно, лише пошта) → отримайте **Access Key** → вставте в адмінці: **Налаштування → Ключ Web3Forms** і увімкніть «Автоматично надсилати замовлення на пошту».

## Фото
Демо-фото десертів згенеровані штучним інтелектом для показу дизайну. Перед запуском замініть їх фото своїх виробів (адмінка → Вироби → Змінити → фото).

## Структура
```
index.html            сторінка
css/style.css         дизайн
js/app.js             вітрина: головна, меню, категорії, фільтри, картка, кошик, оформлення
js/admin.js           адмін-панель
js/store.js           дані: демо (localStorage) або Firebase
js/order.js           текст замовлення, пошта, месенджери
js/seed.js            демо-меню
js/config.js          підключення Firebase
firestore.rules       правила безпеки бази
assets/               логотип, фото
```
Запуск локально: `python -m http.server 8000` → http://localhost:8000
